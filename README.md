# Fart Man

A pass-and-play hangman game for Android. One player sets a secret word and
hands the phone over; the other guesses letters. Every wrong guess bloats Fart
Man a little more, and the sixth one detonates him.

Kotlin, Jetpack Compose, Material 3, Room.

## How to play

1. **Setup** — the word creator enters both players' names, a secret word, and
   an optional hint.
2. **Pass** — a handover screen covers the word so the guesser doesn't see it.
3. **Guess** — tap letters. Correct ones fill the dashes; wrong ones inflate
   Fart Man and rumble the phone.
4. **Result** — deflate him by spelling the word, or set him off with six
   mistakes. Then swap roles and go again.

Every finished round is saved to a local Room database and rolled up into
plays, wins, losses, and win rate on the setup screen.

## Building

Requirements: **JDK 17** and **Android SDK 37**. Both ship with a current
Android Studio; the Gradle wrapper pins Gradle 9.5.0 to match AGP 9.3.1.

```bash
./gradlew assembleDebug
```

Or open the project in Android Studio and run the `app` configuration. There is
no API key, `.env` file, or signing setup to arrange first.

## Testing

Everything runs on the JVM — there is no `androidTest` source set.

```bash
./gradlew test
```

Game logic is covered by plain JUnit tests over `GameUiState` and
`FartManViewModel`. The screens are covered by
[Roborazzi](https://github.com/takahirom/roborazzi) golden images in both light
and dark:

```bash
./gradlew recordRoborazziDebug   # rewrite the goldens
./gradlew verifyRoborazziDebug   # fail on any visual change
```

## Layout

```
app/src/main/java/com/kcverde/fartman/
├── MainActivity.kt          entry point; owns the ViewModel
├── game/                    rules and state, free of Android dependencies
│   ├── GameRules.kt         tuning constants and GamePhase
│   └── GameUiState.kt       one immutable value describing a round
├── data/                    Room entity, DAO, database, repository
└── ui/
    ├── FartManViewModel.kt  all game actions
    ├── MainScreen.kt        phase router and the wrong-guess rumble
    ├── SoundPlayer.kt       SoundPool effects behind a test-friendly interface
    ├── screens/             Setup, Passing, ActiveGame, GameOver
    ├── components/          keyboard, dashes, Fart Man, history, shared bits
    └── theme/               Material 3 light and dark schemes
```

`GameUiState` is deliberately Android-free, so the rules can be tested without
Robolectric.
